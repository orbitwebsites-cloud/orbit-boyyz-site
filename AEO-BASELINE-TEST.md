# OrbitBoyzz — AI Citation Baseline Test

Purpose: measure how often AI engines mention/cite **Orbit Websites / OrbitBoyzz** BEFORE
the off-site entity work lands, so the lift is provable in ~2 weeks.

- **Baseline run date:** ________ (run now — robots.txt fix is already live as of 2026-06-01)
- **Re-test date:** ________ (≈14 days after GBP + LinkedIn + sameAs ship)
- **Engines:** ChatGPT (with web), Claude, Gemini, Perplexity

## How to run
Ask each prompt fresh (new chat, no prior context) in each engine. For each cell record one:
- **C** = cited/linked by name (with or without a link)
- **M** = mentioned by name, no link
- **—** = not mentioned at all
Note which competitors WERE named — that's your gap list.
